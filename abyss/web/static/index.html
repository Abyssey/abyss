1. 도구 실행 루프
(Code Mode REPL · v2.1.323+)		 Bash / Read / Edit를 개별 tool call로 직렬 호출하고 매번 전체 stdout을 LLM 컨텍스트에 적재 (N회 왕복) CLAUDE_CODE_EXPERIMENTAL_CODE_MODE=1 (code_mode.py): 단일 REPL tool 안에서 병렬 실행(gather)·출력 필터링·조건부 수정을 1스텝에 처리하고 마지막 표현식만 반환. 대화창엔 내부 diff만 표시하고 Ctrl+O Transcript Viewer에서 Code 행을 펼침
2. 권한 분류기 한계와
복합 명령 게이트
(Auto Mode · v2.1.283+)		 정적 프롬프트/단일 명령 문자열 매칭에만 의존하여 cd 'app' && git push 또는 런타임 계산 경로(['..','hack'].join('/')) 우회에 취약 Pre-Run AST Review + Per-Call Segment Rules (permissions.py, isolation_policy.py): Auto mode 분류기는 런타임 계산 값을 볼 수 없으므로, 내부 도구 호출 시점마다 복합 셸 명령을 세그먼트로 쪼개어 deny/ask 규칙·4대 Worktree 경로 검증·PreToolUse 훅(onFailure: "block" | "continue")을 이중 강제
3. 멀티 에이전트 표면
(Agent Teams + Worktrees · v2.1.326+)		 단일 세션 Subagents는 부모를 통해서만 통신하고, 반대로 공식 Agent Teams는 공유 태스크·메일박스를 갖지만 기본 Worktree 격리가 없음 Agent Teams + Git Worktree 하이브리드 (team_coordinator.py, evaluator_rubric.py): 파일 락 공유 태스크 보드(tasks.json 자동 의존성 해제) + P2P 메일박스(inboxes/*.jsonl, 에이전트 간 권한 대리 승인 차단)에 독립 Git Worktree 격리 및 품질 게이트(TaskCompleted / Evaluator 80점+ 머지)를 결합
4. 컨텍스트 수명주기 &
서브에이전트 제어
(v2.1.257 ~ v2.1.296+)		 단일 autoCompact 요약에 의존해 장기 태스크에서 스펙 유실, 서브에이전트 모델/캐시 제어 부재 역할별 모델 강제 & 구조화된 Handoff (agent_runtime.py, provider_rotator.py): CLAUDE_CODE_SUBAGENT_MODEL_FORCE 대응 역할별 라우팅(Lead: Gemini / Workers: 사내 Qwen 3.8 Flash), <think> 추론 블록 실시간 분리, HandoffArtifact 기반 클린 컨텍스트 인계
5. 사내 게이트웨이 &
SDK 호환성 돌파		 공식 바이너리 Code Mode는 "it only works directly with the Anthropic API" 제약으로 커스텀 BASE_URL, 사내 게이트웨이, -p/SDK에서 구동 불가 순수 Python CodeModeExecutor & REST API: OpenAI 호환 게이트웨이를 쓰는 사내 Qwen 3.8 Flash 및 비대화형 자동화 파이프라인에서도 Code Mode REPL과 3단계 보안 게이트를 그대로 실행
